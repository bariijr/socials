A · Hide "Details" below tablet

The view-mode toggle only offers Tile/Large/Small on phone width — the raw table option isn't shown at all, since it genuinely can't work in that space. Simplest, safest.

List (scrolls →)

B · Keep it, horizontal scroll

Every view mode stays available everywhere, including List/Details. The table just scrolls sideways within its own container on narrow screens. No behavior change, more finger-scrolling.

C · Auto-restack rows as cards

"Details" stays selectable everywhere, but below tablet width each table row automatically renders as a small stacked label:value card instead of a `<table>` row — no data lost, no sideways scrolling, but more work to build since it changes how every page's Details mode renders on narrow screens.
